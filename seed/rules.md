# Seed rules — the promotion target (§7.3)

Read by `vid init` after inventory derivation, before ratification. Each
entry is a PROPOSAL the owner confirms or vetoes at recognition speed,
classified into an existing evidence tier: testable behavior → ledger test
(a ROW); "everywhere" rule → rule row with a census command (RULE);
judgment-only → checklist line. Confirmed rows are tagged `origin: domain`.

**This file ships empty.** It grows only by promotion: at run end the owner
marks which of the run's new rule rows are general — domain-level or
universal — and they land here, stack-neutrally formulated (the concrete
census command is always re-derived from the next scaffold, never copied).
A seeded entry that fires nothing across two runs is dropped (the
complexity law). The genus step's universal and stack layers come from the
vid-init skill itself; this library carries what runs have learned.

Entry format:

    - <stack-neutral statement>. — tier: <ledger test | rule row | checklist line> | scope: <universal | domain: <genus>> | evidence: <run/finding>
