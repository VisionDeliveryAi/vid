# Fixture seed — basic

I run a small climbing gym and want a wall-topo board: routesetters
post each new route (wall sector, grade, color, setter, date), climbers
browse the current routes on a public page and tick the ones they have
climbed. When a route is stripped it should disappear from the current
list but climbers keep their tick history. No payments, no bookings —
the gym software does that already.
