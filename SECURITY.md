# Reporting a security vulnerability

ViD / VisionDelivery.ai is maintained, operated and published by [AI Value Link](https://aivaluelink.com).

Please report suspected vulnerabilities privately to **contact@AIValueLink.com**, with the subject **ViD security report**.

Include, where available:

- The affected version or commit and relevant configuration.
- A description of the vulnerability and its potential impact.
- Reproduction steps or a minimal proof of concept.
- A safe way to contact you for follow-up.

Please keep exploit details out of public issues and pull requests while the report is being assessed. Do not include live credentials, customer data or other sensitive material in your report, and reproduce the issue only in environments you are authorised to test.

For general questions and non-security bugs, use the official repository's available discussion or issue channels.
